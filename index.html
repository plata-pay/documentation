Plata API

19 октября 2026 г.

Содержание
Создание инвойсаПроверка инвойса

Создание и проверка инвойсов Plata. Запросы отправляются с вашего сервера. Ключ передаётся в поле merchant_token.

  1. Создайте ключ в личном кабинете и сохраните его на сервере.
  2. Создайте инвойс, сохраните его id вместе с заказом и откройте покупателю полученный url.
  3. Проверьте статус инвойса с сервера. При paid выдайте заказ один раз.

Создание инвойса

POST · Content-Type: application/json

https://plata-main.dpl-payments.workers.dev/api/orders

Формат запроса

{
  "merchant_token": "YOUR_MERCHANT_TOKEN",
  "amount": "150.00"
}

merchant_token — ваш ключ. amount — сумма в рублях.

Ответ · основные поля

{
  "id": "xxxx-xxxx-xxxx-xxxx",
  "url": "https://plata-pay.github.io/order/xxxx-xxxx-xxxx-xxxx"
}

id — идентификатор инвойса. url — ссылка для оплаты.

Примеры запроса

const response = await fetch(
  "https://plata-main.dpl-payments.workers.dev/api/orders",
  {
    method: "POST",
    headers: {
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      "merchant_token": "YOUR_MERCHANT_TOKEN",
      "amount": "150.00"
    })
  }
);

const result = await response.json();
if (!response.ok) throw new Error(JSON.stringify(result));
console.log(result);

Проверка инвойса

Тот же адрес, метод POST и заголовок Content-Type: application/json.

Формат запроса

{
  "merchant_token": "YOUR_MERCHANT_TOKEN",
  "id": "INVOICE_ID"
}

id — идентификатор созданного инвойса.

Ответ · поле статуса

{
  "status": "paid"
}

Показано поле status, используемое для проверки оплаты.

СтатусЗначение
pendingОжидает оплаты
paidОплачен
expiredСрок действия истёк
cancelledОтменён

Примеры запроса

const response = await fetch(
  "https://plata-main.dpl-payments.workers.dev/api/orders",
  {
    method: "POST",
    headers: {
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      "merchant_token": "YOUR_MERCHANT_TOKEN",
      "id": "INVOICE_ID"
    })
  }
);

const result = await response.json();
if (!response.ok) throw new Error(JSON.stringify(result));
console.log(result);

Выдавайте товар или услугу только после серверной проверки статуса paid. Возврат покупателя со страницы оплаты сам по себе не подтверждает платёж.

При pending заказ ещё не оплачен. Проверяйте статус по действию пользователя или с ограниченным интервалом на сервере. Повторный ответ paid не должен приводить к повторной выдаче заказа.

Проверяйте HTTP-статус ответа перед обработкой данных. В JavaScript при HTTP-ошибке response.ok равно false. При сетевом сбое создания инвойса не повторяйте запрос автоматически: первый запрос мог уже выполниться.
